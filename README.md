# 向日市ストーリーWebアプリ 仕様書

スマホ縦画面向けの、ストーリー型ゲーム風Webアプリ。向日市周辺のマップを舞台に、キャラクターとのストーリーとAI会話を楽しむ。

## 全体の流れ

タイトル → プロローグ → チュートリアル(早良) → ホーム → マップ → VS崇徳(余裕があれば) → 早良(ラスボス) → ED

- ED後は、ホーム画面で自由に動けるモード(クリア後モード)になる
- 「もう一度はじめから」でストーリーをやり直せる(クリア記録は残る)

## ファイル構成

```
index.html
css/style.css
js/main.js    画面切り替え
js/state.js   状態管理
js/story.js   ストーリー・進捗
js/map.js     マップ・ピン
js/chat.js    AI会話(別実装・後から組み込み)
```

## 各ファイルの仕様

### index.html(画面の骨組み)

- 画面: タイトル / プロローグ / チュートリアル / ホーム / マップ / VS崇徳 / ED / 会話
- タイトル: 「ゲームstart」ボタン
- プロローグ・チュートリアル: キャラ + テキスト欄
- ホーム: メニューボタン + 進捗バー(例: 20%)
- メニューを押すと展開し、「マップ」と「会話」の項目が出る
- 会話画面: キャラ + テキスト欄 + キーボード入力
- スクリプトは `<script type="module" src="js/main.js"></script>` で読み込む

### css/style.css(見た目)

- 縦画面前提。`height: 100dvh` を使う
- ボタンは指で押しやすい大きさにする
- メニュー展開、進捗バー、テキスト欄のデザイン

### js/main.js(画面切り替え)

- 画面の表示・非表示を切り替える
- 各モジュールを読み込む

### js/state.js(状態管理)

保持するデータ:

| 項目 | 内容 |
| --- | --- |
| `currentScene` | 現在のシーン |
| `cleared` | 一度でもクリアしたか |
| `unlockedPins` | 解放済みのピン |
| `progress` | 進捗度(0〜100) |

- `localStorage` に保存する(読み書きは try/catch で囲む)
- `finishGame()`: EDでクリア扱いにし、ホームへ戻す
- `restartStory()`: ストーリーを最初からやり直す(`cleared` は残す)

### js/story.js(ストーリー)

- シーンをデータとして管理する(id / キャラ / テキスト / 次のシーン)
- 進捗度は、クリアしたシーン数をもとに自動計算する
- キャラクター: かぐや、早良親王、崇徳天皇

### js/map.js(マップ)

- Leaflet + OpenStreetMap で向日市周辺を表示する
- 中心座標の目安: 向日市役所付近(約 34.95, 135.70)
- ピン一覧: 長岡宮跡 / 竹の径 / 資料館 / 向日神社
- 今回は **長岡宮跡と資料館のみ** 移動可能。他はロック表示(一部デバッグ用)
- ピンを押したとき
  - 通常時: ストーリーが進む
  - クリア後(`cleared: true`): そのスポットの解説・会話が開く(ストーリーは進まない)

### js/chat.js(AI会話)

- AI部分は別で作り、後から組み込めるようにする
- 公開する関数は `sendMessage(text, mode)` のみ
- `mode`: `story`(進捗に沿った会話) / `free`(クリア後の自由会話)
- 最初は固定の返事を返すダミー実装にする
- 本物のAIにするときは中継サーバー(Cloudflare Workers、Vercel など)を挟み、**APIキーをブラウザ側のコードやリポジトリに入れない**(リポジトリは公開のため)

## クリア後モード

- ホームの進捗を100%で表示する
- マップのピンを全て解放し、ストーリーを進めずに解説・会話を開く
- 会話は、向日市の歴史についての自由会話にする

## 素材(画像)

- must: マップ、かぐや、早良親王、崇徳天皇
- better: 背景(竹など)、アイテム

## 開発メモ

- VS Code の拡張機能「Live Server」で開いて動作確認する(ファイルを直接開くと `import` が動かないことがある)
- デバッグ用に「シーンスキップ」「全ピン解放」のスイッチを用意しておく
- 作る順番: タイトル → プロローグ → ホーム → マップ(長岡宮跡)まで一本通してから、他のシーンを足す
- 公開は GitHub Pages を想定
