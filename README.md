# 向日市ストーリーWebアプリ 仕様書

スマホ縦画面向けの、ストーリー型ゲーム風Webアプリ。向日市周辺のマップを舞台に、キャラクターとのストーリーとAI会話を楽しむ。

## 全体の流れ

プロローグ → マップで5つの章を順に進む → ED

| 順番 | キャラ | 場所 | ゲーム(id) |
| --- | --- | --- | --- |
| 1 | 早良 | 長岡宮跡 | 弾幕・チュートリアル(`danmaku_tutorial`) |
| 2 | 平将門 | 向日神社 | ワード探し(`wordsearch`) |
| 3 | 菅原道真 | 千代桜天満宮 | スライドパズル(`slide_puzzle`) |
| 4 | 崇徳上皇 | 竹の径 | RUN ESCAPE(`runner`) |
| 5 | 早良 | 長岡宮跡 | 弾幕・ラスボス(`danmaku_boss`) |

- 長岡宮跡は最初と最後の2回使う
- ED後は、ホーム画面で自由に動けるモード(クリア後モード)になる
- 「はじめから」でストーリーをやり直せる(クリア記録は残る)
- ゲームは `js/games.js` に登録する。**5本とも本物が入っている**(下の「ミニゲーム」参照)
- 資料館のピンはストーリーでは使わず、クリア後の解説用

## ファイル構成

```
index.html
css/style.css
js/main.js    画面切り替え
js/state.js   状態管理
js/story.js   ストーリー・進捗
js/map.js     マップ・ピン
js/games.js   ミニゲームの入口(start(container, onFinish) の形で登録)
js/games/kit.js               弾幕・ランナー共通の土台(操作・ループ・後始末)
js/games/danmaku_tutorial.js  第一章の弾幕(負けイベント)
js/games/wordsearch.js        第二章のワード探し(平将門)
js/games/slide_puzzle.js      第三章のスライドパズル(菅原道真・記憶の絵鏡)
js/games/runner.js            第四章のRUN ESCAPE(崇徳上皇)
js/games/danmaku_boss.js      最終章のラスボス弾幕
js/chat.js    AI会話(別実装・後から組み込み)
```

## 各ファイルの仕様

### index.html(画面の骨組み)

- 画面: タイトル / プロローグ / チュートリアル / ホーム / マップ / VS崇徳 / ED / 会話
- タイトル: 「ゲームstart」ボタン
- プロローグ・チュートリアル: キャラ + テキスト欄
- ホーム: メニューボタン + 進捗バー(例: 20%)
- メニューを押すと展開し、「マップ」と「会話」の項目が出る
- 会話画面: キャラ + テキスト欄 + キーボード入力
- スクリプトは `<script type="module" src="js/main.js"></script>` で読み込む

### css/style.css(見た目)

- 縦画面前提。`height: 100dvh` を使う
- ボタンは指で押しやすい大きさにする
- メニュー展開、進捗バー、テキスト欄のデザイン

### js/main.js(画面切り替え)

- 画面の表示・非表示を切り替える
- 各モジュールを読み込む

### js/state.js(状態管理)

保持するデータ:

| 項目 | 内容 |
| --- | --- |
| `currentScene` | 現在のシーン |
| `cleared` | 一度でもクリアしたか |
| `unlockedPins` | 解放済みのピン |
| `progress` | 進捗度(0〜100) |

- `localStorage` に保存する(読み書きは try/catch で囲む)
- `finishGame()`: EDでクリア扱いにし、ホームへ戻す
- `restartStory()`: ストーリーを最初からやり直す(`cleared` は残す)

### js/story.js(ストーリー)

- シーンをデータとして管理する(id / キャラ / テキスト / 次のシーン)
- 進捗度は、クリアしたシーン数をもとに自動計算する
- キャラクター: かぐや、早良親王、崇徳天皇

### js/map.js(マップ)

- Leaflet + OpenStreetMap で向日市周辺を表示する
- 中心座標の目安: 向日市役所付近(約 34.95, 135.70)
- ピン一覧: 長岡宮跡 / 竹の径 / 資料館 / 向日神社
- 今回は **長岡宮跡と資料館のみ** 移動可能。他はロック表示(一部デバッグ用)
- ピンを押したとき
  - 通常時: ストーリーが進む
  - クリア後(`cleared: true`): そのスポットの解説・会話が開く(ストーリーは進まない)

### js/chat.js(AI会話)

- AI部分は別で作り、後から組み込めるようにする
- 公開する関数は `sendMessage(text, mode)` のみ
- `mode`: `story`(進捗に沿った会話) / `free`(クリア後の自由会話)
- 最初は固定の返事を返すダミー実装にする
- 本物のAIにするときは中継サーバー(Cloudflare Workers、Vercel など)を挟み、**APIキーをブラウザ側のコードやリポジトリに入れない**(リポジトリは公開のため)

## ミニゲーム

どのゲームも `start(box, onFinish)` の形。終わったら `onFinish("clear")` か `onFinish("fail")` を呼び、戻り値の関数で後始末する。

| ゲーム | 元のファイル | 操作 | 結果 |
| --- | --- | --- | --- |
| 弾幕(チュートリアル) | `index.html` | 十字ボタン / 画面ドラッグ / 矢印・WASD | 必ず fail(負けイベント。進む) |
| ワード探し | `kotobaasobi.html` | タップ | 全部見つけて clear |
| スライドパズル | `main_1.cpp`(4×4パズル) | タップ | 完成で clear |
| RUN ESCAPE | `main.cpp` | 画面タップ / JUMPボタン / スペース | 60秒で clear、ぶつかると fail |
| 弾幕(ラスボス) | `index2_1.html` | 十字ボタン / 画面ドラッグ / 矢印 | ボスHP0で clear、自機HP0で fail |

- スライドパズルの絵は、いまはプログラムで描いた仮のもの。`js/games/slide_puzzle.js` の `PICTURE_URL` に画像のパスを書くと差し替わる
- 混ぜる回数は `SCRAMBLE_DEPTH`(スライドパズル)で調整できる

## クリア後モード

- ホームの進捗を100%で表示する
- マップのピンを全て解放し、ストーリーを進めずに解説・会話を開く
- 会話は、向日市の歴史についての自由会話にする

## 素材(画像)

- must: マップ、かぐや、早良親王、崇徳天皇
- better: 背景(竹など)、アイテム

## 開発メモ

- VS Code の拡張機能「Live Server」で開いて動作確認する(ファイルを直接開くと `import` が動かないことがある)
- デバッグ用に「シーンスキップ」「全ピン解放」のスイッチを用意しておく
- 作る順番: タイトル → プロローグ → ホーム → マップ(長岡宮跡)まで一本通してから、他のシーンを足す
- 公開は GitHub Pages を想定
